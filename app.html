Cookie Bridge local · unpacked

Moves ordinary cookies between two local Chromium profiles through a one-use encrypted bundle. Nothing leaves this machine.

note

The bundle can contain active login tokens — treat it like a temporary password vault. Delete it after use and remove the unpacked extension when migration is done.

Export from your source browser

Run this in the source browser profile whose sessions you want to migrate.

02

Import into your destination browser

Load the same unpacked extension in the destination browser, then inspect the bundle before writing anything.

existing destination cookies

Regular-profile cookies only. Device-bound sessions, passkeys, localStorage, IndexedDB, client certificates, and service-worker state are outside this bundle.
