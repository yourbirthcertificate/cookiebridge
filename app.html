LOCAL CHROMIUM MIGRATION

Cookie Bridge

Move ordinary browser cookies through a one-use encrypted bundle. Nothing is uploaded.

Local only
!

Treat the bundle like a temporary password vault

It can contain active login tokens. Use it immediately, delete it afterwards, and remove this unpacked extension when the migration is complete.

Import into Vivaldi

Existing Vivaldi cookies

Regular-profile cookies only. Device-bound sessions, passkeys, localStorage, IndexedDB, client certificates, and service-worker state are outside this bundle.
